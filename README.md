# Bushra AI Agent (বুশরা)

ব্যক্তিগত Android এআই সহকারী — ক্লেমরফিজম UI, বাংলা ভয়েস, Gemini (ফ্রি API) দিয়ে চলে।
রুট বা Shizuku লাগে না। নিজের ফোনে ব্যক্তিগত ব্যবহারের জন্য।

## ফোনে ইনস্টল (পিসি লাগে না)
1. কোড এই রিপোতে আপলোড করুন → **Actions** ট্যাবে "Build APK" নিজে চলবে (৫-১০ মিনিট)।
2. সবুজ টিক এলে **Releases → latest** থেকে `app-debug.apk` ফোনে নামান।
3. ইনস্টল করুন (প্রথমবার "অজানা উৎস থেকে ইনস্টল" অনুমতি দিতে হবে)।
4. অ্যাপ খুলে **পারমিশন** ট্যাবে সব চালু করুন, বিশেষ করে **Accessibility**।
   Android 13+ এ আটকে থাকলে: অ্যাপের তথ্য পেজ → ⋮ → *Allow restricted settings*।
5. **সেটিংস** ট্যাবে Gemini API key বসান (aistudio.google.com থেকে ফ্রি)।
6. **হোম**-এ "চালু করো" চাপুন, তারপর বলুন: **"বুশরা, আম্মুকে ফোন দাও"**।

## যা পারে (৩৪টি অ্যাকশন)
কল (সাধারণ ও WhatsApp), SMS পাঠানো/পড়া, WhatsApp মেসেজ, অ্যাপ খোলা, অ্যালার্ম/টাইমার/ইভেন্ট,
ফ্ল্যাশলাইট, ভলিউম, উজ্জ্বলতা, রিংগার মোড, সেটিংস পেজ, ওয়েব/ম্যাপ/YouTube,
ইমেইল ড্রাফট, ক্লিপবোর্ড, ডিভাইস তথ্য, স্ক্রিন পড়া + ট্যাপ/লেখা/স্ক্রল/সিস্টেম বাটন
(অ্যাপের ভেতরের কাজ), দীর্ঘমেয়াদি স্মৃতি, ইনকামিং কল সামলানো (ধরব/মেসেজ পাঠাব)।

## নিরাপত্তা
- হোমের **"অ্যাকশন বন্ধ"** সুইচ এক ট্যাপে সব অ্যাকশন থামায়।
- ব্যাংক/পেমেন্ট/পাসওয়ার্ড/OTP-র কাজের আগে বুশরা মুখে নিশ্চিত হয়ে নেয়।
- API key শুধু ফোনে থাকে, কোডে নেই।

## সীমাবদ্ধতা (সৎভাবে)
- Android কল-অডিও ধরতে দেয় না; কলারের সাথে এআই-র কথা শুধু স্পিকারফোন পদ্ধতিতে, পরীক্ষামূলক।
- লক স্ক্রিনে কল/SMS/অ্যালার্ম/ফ্ল্যাশলাইট চলে; অ্যাপ খুলতে আনলক লাগতে পারে।
- ফ্রি Gemini-র অনুরোধ-সীমা আছে; একাধিক মডেল ফলব্যাক হিসেবে দেওয়া আছে।
- ফোনভেদে ব্যাকগ্রাউন্ড অ্যাপ বন্ধ করে দেওয়ার নিয়ম আলাদা: ব্যাটারি অপ্টিমাইজেশন বন্ধ রাখুন।
